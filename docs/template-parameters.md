# Template parameters (`jex new` / `dotnet new jex`)

**English** | [简体中文](template-parameters.zh-CN.md)

`jex new <Name> ...` passes the options unchanged to `dotnet new jex -n <Name> ...`, and also supports `--template-version <version>` (use that template package version, installing it when needed) and `--no-install` (never install or switch the template package).

| Option | Short | Type / default | Effect |
|---|---|---|---|
| `-n, --name` | | text / current directory name | Project and namespace name. `Acme.Shop` → `Acme.Shop.*`; names containing `-` become valid namespaces (`my-api` → `my_api`), and directories match the namespaces; database and compose project names use kebab-case (`acme-shop`). |
| `--database` | `-db` | `sqlite` | See the table below |
| `--use-aspire` | `-aspire` | `false` | Generates `src/*.AppHost` and adds it to the solution; run it with `jex run --aspire`. `*.ServiceDefaults` is always generated. |
| `--include-ai-docs` | `-ai` | `true` | When `false`, `AGENTS.md`, `CLAUDE.md`, `.claude/`, `.mcp.json`, `.github/copilot-instructions.md` and `.github/instructions/` are not generated. |
| `--include-docker` | `-docker` | `true` | When `false`, `Dockerfile`, `.dockerignore`, `docker-compose.yml`, `.env.example` and `docker/` are not generated; `jex infra` reports that there is no compose file. |
| `--http-port` | `-hp` | random 5000–5300 | HTTP port in launchSettings and the `.http` file |
| `--https-port` | `-hsp` | random 7000–7300 | HTTPS port in launchSettings |
| `--skip-restore` | `-sr` | `false` | Do not run `dotnet restore` after generating |

## `--database`

| Value | FreeSql provider | DbUp | Default connection string | compose profile | Testcontainers |
|---|---|---|---|---|---|
| `sqlite` | `FreeSql.Provider.Sqlite` | `dbup-sqlite` | `Data Source=<name>.db` | none | not needed |
| `postgresql` | `FreeSql.Provider.PostgreSQL` | `dbup-postgresql` | `Host=localhost;Port=5432;…` | `postgresql` | `Testcontainers.PostgreSql` |
| `sqlserver` | `FreeSql.Provider.SqlServer` | `dbup-sqlserver` | `Server=localhost,1433;…` | `sqlserver` | `Testcontainers.MsSql` |
| `mysql` | `FreeSql.Provider.MySqlConnector` | `dbup-mysql` | `Server=localhost;Port=3306;…` | `mysql` | `Testcontainers.MySql` |

Integration tests use a temporary SQLite database by default (no Docker needed). With `TEST_DATABASE=provider` they use the project's real provider (Testcontainers; fails when Docker is unavailable); `TEST_DATABASE=auto` falls back to SQLite when there is no local Docker.

## Values made unique on every generation

- The development JWT secret (`appsettings.Development.json`) and `UserSecretsId`: regenerated by a GUID generator.
- HTTP/HTTPS ports: random (can be fixed with the options).
